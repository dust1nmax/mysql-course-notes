# MySQL 课程全集案例手册

把 B 站《黑马程序员 MySQL 入门到精通》整套课程（BV1Kr4y1i7ru，共 **195 个分 P**）逐集整理成一份可查阅、可照抄的案例手册：每一集对应一条「讲解要点 + 课堂案例 SQL + 通用模板」。

- 主文档：[MySQL课程-全集案例手册.md](./MySQL课程-全集案例手册.md)
- 规模：195 节、272 段 SQL、135 条模板、85 张速查表
- 适用：边看课边对照练习，或学完后当成 MySQL 语法速查表

## 内容结构

| 部分 | 分 P | 覆盖内容 |
|---|---|---|
| 基础篇 | P1–P57 | 数据库概念、SQL 分类、DDL/DML/DQL/DCL、函数、约束、多表查询、事务 |
| 进阶篇 | P58–P152 | 存储引擎、索引、SQL 优化、视图、存储过程/函数、触发器、锁、InnoDB 架构、MVCC、日志、主从复制、分库分表 |
| 运维篇 | P153–P195 | 日志、备份与恢复、主从复制搭建、MyCat 分片与读写分离 |
| 附录 | — | 课程全部示例表结构（emp、dept、salgrade、student、course、tb_user、tb_sku、user_logs 等） |

## 怎么用

1. **先看模板总览**：文档开头按语法类型给出 19 类骨架，查语法比翻目录快。
2. **再按分 P 精读**：每个小节格式固定——
   - 知识点表（函数/关键字 ｜ 作用）
   - `> 模板：` 一行通用骨架
   - 课堂案例 SQL（可直接在示例库上跑）
3. **模板符号**：`[]` 可选、`...` 可续写、`｜` 分隔同类写法；中文占位符替换成自己的表名/列名即可。
4. **练习环境**：先执行附录里的建表语句与示例数据，案例即可直接复现。
