## 今日知识点

| 主题 | 要点 |
|---|---|
| `GROUP BY` | 分组是 `GROUP BY` 干的；`SELECT` 只决定每组输出哪些列，有几组输出几行 |
| `COUNT(*)` | 数行数，不看 NULL；`COUNT(列)` 跳过 NULL；`COUNT(DISTINCT 列)` 去重 |
| `HAVING` | 过滤"组"，在 `GROUP BY` 之后；聚合条件不能放 `WHERE` |
| `LEFT JOIN` | 左表全保留，右表匹配不上补 NULL；一对多会放大行数 |

执行顺序：`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`

## 练习 SQL

```sql
-- 60 岁以下按性别统计人数
SELECT gender, COUNT(*) AS 人数
FROM emp
WHERE age < 60
GROUP BY gender
HAVING COUNT(*) >= 2;

-- 每个人 + 所在城市（没地址的人也保留）
SELECT p.firstName, p.lastName, a.city, a.state
FROM Person p
LEFT JOIN Address a ON p.personId = a.personId;
```
